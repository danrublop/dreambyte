# Third-party audio — sources and licenses

This file records **upstream projects and licenses** for audio that may ship with Dreambyte (for example under `apps/desktop/public/sfx-library/`). It is not legal advice; verify before commercial distribution.

## ZzFX (current bundled procedural library)

- **Source:** [KilledByAPixel/ZzFX](https://github.com/KilledByAPixel/ZzFX)
- **License:** MIT
- **Use here:** In-app synthesis and WAVs generated by `npm run sfx-library:zzfx` (`librarySource: "zzfx"` in `apps/desktop/public/sfx-library/manifest.json`).

## SoLoud (optional imports — engine / assets)

- **Source:** [jarikomppa/soloud](https://github.com/jarikomppa/soloud)
- **License:** SoLoud proper is **zlib/libpng** (permissive; **commercial use is explicitly allowed**). The upstream `LICENSE` file also notes bundled third-party code with similarly liberal terms; see [SoLoud legal / manual](http://soloud-audio.com/legal.html) and the full text in the repo:  
  [github.com/jarikomppa/soloud/blob/master/LICENSE](https://github.com/jarikomppa/soloud/blob/master/LICENSE)

**zlib/libpng summary (SoLoud):** use for any purpose including commercial apps; do not misrepresent origin; mark altered sources; keep the license notice in source distributions.

**Using SoLoud in this project:** SoLoud is a **C/C++ engine** (not a JS npm package). Typical approaches are WASM/native bindings or exporting **audio files** from SoLoud-powered tools/demos. Any WAV/OGG you add from SoLoud (or generated with it) should be listed in `manifest.json` with:

- `license`: e.g. `zlib/libpng (SoLoud)` or as required by the specific file’s origin
- `librarySource`: `"soloud"` (see `apps/desktop/src/lib/audio/sfx-local-manifest.ts`)

Add files under `apps/desktop/public/sfx-library/{category}/` using a `soloud-` filename prefix so they stay git-tracked alongside the `zzfx-*.wav` exception in `.gitignore`.

## react-sounds (optional imports — curated SFX pack)

- **Source:** [e3ntity/react-sounds](https://github.com/e3ntity/react-sounds)
- **License:** **MIT** (explicitly allows commercial use; retain copyright notice in copies of the software — see the repo [LICENSE](https://github.com/e3ntity/react-sounds/blob/master/LICENSE)).
- **What it is:** A **React + Howler.js** library. Sounds are usually loaded from a **CDN** at runtime; the repo also documents **offline / self-host** via their CLI (`bin` / `scripts` in the package).

**Using it in Dreambyte:** We do **not** depend on `react-sounds` in the editor bundle today. The practical approach matches other static SFX:

1. **Self-host** clips (e.g. using the project’s documented download flow) into `apps/desktop/public/sfx-library/{category}/`.
2. Name files with a **`react-sounds-` prefix** (e.g. `ui/react-sounds-button_1.mp3`) so `.gitignore` allows them.
3. Add manifest entries with `librarySource: "react-sounds"` and `license: "MIT (react-sounds)"` (or the exact notice you use for shipped copies).

That keeps **export, publish, and the render server** on same-origin URLs under `/sfx-library/`, instead of runtime CDN URLs inside scene HTML.

## Music Megathread (reference only — not a product catalog)

- **Source:** [MoonWalker440/Music-Megathread](https://github.com/MoonWalker440/Music-Megathread)
- **What it is:** A large **README of links** to music-related apps, sites, players, discovery tools, and similar resources. It is **not** a repository of downloadable tracks under one license, and it is **not** code or assets this app can “import” the way we bundle ZzFX WAVs or self-hosted SFX.
- **Licensing / commercial use:** Entries point to **many unrelated services and tools**. Some are FOSS; many are third-party commercial or **grey-area** (e.g. unofficial clients, downloaders). **Nothing in that list is automatically safe for commercial video soundtracks.** You must follow **each site’s terms** and, where applicable, **performance / sync rights** for published video.

**Dreambyte:** Background music in the editor is intended to come from **cleared sources** — primarily **Pixabay Music** and **Freesound** via `add_music` with `source: "library"` (see `apps/desktop/src/lib/audio/providers/pixabay-music.ts`, `freesound-music.ts`), or **your own uploads** under terms you control. Use the Megathread as a **personal discovery bookmark list**, not as a built-in music library.

## Native music composer (`add_music` source `compose` — local, $0, no provider)

The agent can compose ORIGINAL background music itself, fully offline, with no external
service or API key (`add_music` with `source: "compose"`). It uses these bundled/open-source components:

- **spessasynth_core** ([spessasus/spessasynth_core](https://github.com/spessasus/SpessaSynth)) —
  **Apache-2.0**. A pure-JavaScript SoundFont (SF2/SF3) synthesizer. Renders MIDI + a SoundFont
  to PCM offline in Node; we encode the result to WAV via its bundled `audioToWav`. No native
  binary, no WASM module to ship, no LGPL — chosen over a FluidSynth (LGPL) wrapper for exactly
  this reason. Used in `apps/desktop/src/lib/audio/composer/render.ts`.
- **MuseScore_General.sf3** ([MuseScore General SoundFont](https://musescore.org/en/node/317991)) —
  **MIT**. The multi-sampled General-MIDI instrument set (piano, pads, bass, drums, …). Commercial
  use is permitted; waveforms rendered from it are "copies or substantial portions" of the
  soundfont, so the MIT notice is retained here. It is **not** committed to git (40MB); it is
  fetched at build time by `apps/desktop/scripts/assets/fetch-soundfont.mjs` (checksum-verified) into
  `apps/desktop/public/soundfonts/` (git-ignored) and bundled into the packaged app.
- **Tonal** ([tonaljs/tonal](https://github.com/tonaljs/tonal)) — **MIT**. Music-theory helpers
  (chords, scales, transposition) used by `apps/desktop/src/lib/audio/composer/arrange.ts` to voice the chord
  progressions. Theory only; produces no audio.

The output is a normal WAV attached as the scene's `MusicTrack` (`provider: 'native-sequencer'`),
consumed unchanged by preview and the ffmpeg export path — verified end-to-end by
`apps/desktop/src/lib/audio/composer/export-smoke.test.ts`.

### ML melody (`add_music` source `compose`, `melody: "ml"`)

Optional AI-generated lead melodies use Magenta, fully local + $0 after a one-time weight cache:

- **@magenta/music** ([magenta/magenta-js](https://github.com/magenta/magenta-js)) — **Apache-2.0**.
  ImprovRNN generates a chord-conditioned melody. Runs headless in Node via an isolated worker
  (`apps/desktop/src/lib/audio/composer/ml-melody-worker.cjs`); the playback `Player` (which needs Tone.js) is never
  used — we render the generated MIDI through spessasynth.
- **@tensorflow/tfjs** — **Apache-2.0**. Pure-JS CPU backend (no native tfjs-node build).
- **ImprovRNN checkpoint** (`chord_pitches_improv`, ~5MB) — Magenta model weights, fetched at build
  time by `apps/desktop/scripts/assets/fetch-magenta.mjs` into `apps/desktop/public/magenta/` (git-ignored) and loaded offline.

### Native SFX synth (`add_sfx` source `synthesize` — local, $0, no provider)

The agent synthesizes sound effects itself, fully offline, two engines:

- **ZzFX** ([KilledByAPixel/ZzFX](https://github.com/KilledByAPixel/ZzFX)) — **MIT**. Exact curated
  archetypes + layered compounds (apps/desktop/src/lib/audio/sfx/synth.ts). Already used by the bundled SFX library.
- **jsfxr** ([chr15m/jsfxr](https://github.com/chr15m/jsfxr)) — **Unlicense (public domain)**. The
  full sfxr engine; "generate" mode produces a fresh, varied sound per category (explosion, laser,
  coin, powerup, hit, jump, blip, tone) — apps/desktop/src/lib/audio/sfx/sfxr.ts. Renders to WAV in pure JS (no
  AudioContext); Math.random is seeded for deterministic, cacheable output.

Both are bundled deps (no per-use network). For REALISTIC/recorded SFX (a real bark, rain), use
`add_sfx` with `source: "library"` (Freesound/Pixabay/ElevenLabs) — the open-source local options for realistic foley
(Meta AudioGen, Stable Audio, FoleyCrafter) are heavy Python+GPU models, not in-app-feasible.

### CC0 foley pack (real recordings — bundled in the SFX library)

Real-recorded natural foley the agent can use locally + $0 (doors, metal, wood, glass, water,
paper, springs, dishes, bells). Imported into `apps/desktop/public/sfx-library/foley/` (`cc0-*.ogg`) with a
`foley` manifest category; the agent finds them via `add_sfx` (`source: "library"`).

- **Source:** [OpenGameArt "100 CC0 SFX"](https://opengameart.org/content/100-cc0-sfx) — 100 sounds
  recorded on an Android device, dedicated to the **public domain (CC0)**. No attribution required.
- **Reproduce:** `node apps/desktop/scripts/assets/import-cc0-foley.mjs` (downloads + copies + merges the manifest, idempotent).

### Kenney CC0 packs (real recordings — bundled in the SFX library)

Recorded footsteps, impacts, UI, digital/retro, and RPG sounds, listed in the manifest with
`librarySource: "kenney-cc0"` and `license: "CC0 (Kenney)"`.

- **Source:** [Kenney](https://kenney.nl/assets) audio packs `impact-sounds`, `interface-sounds`,
  `digital-audio`, and `rpg-audio` — dedicated to the **public domain (CC0)**. No attribution required.
- **Reproduce:** `npm run sfx-library:packs` (`apps/desktop/scripts/assets/fetch-sfx-packs.mjs`) downloads the packs into
  `apps/desktop/public/sfx-library/kenney/` (git-ignored) and merges the manifest rows. `npm run assets:fetch`,
  which every `dist*` script runs, includes this step.
