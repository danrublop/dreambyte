dreambyteEditor Design System
Dark
Monochrome editorial, one signal. Surfaces are neutral; the only chromatic color is Signal Blue (--accent), reserved for playhead, selection, active tab, and focus. Actions are black/white and invert per theme. Flip the toggle (top right) to review the dark and light states. Full spec in docs/EDITOR-DESIGN.md.
01

Color & Roles

Surfaces — inverted elevation on dark (panels lift lighter), shadow depth on light.

Text ladder — ink to ash. Body never goes below --mute.

Action language & the one functional accent.

Status (semantic, sparing) & chart palette (data viz only).

02

Typography

Inter Variable. UI default 13px, body 14px. Headings 600. Uppercase only for eyebrow / micro-caps.

03

Buttons & Controls

Compact rounded-rectangles (--radius-md) are the default — clean and Figma-like. Pills are opt-in for hero CTAs only (welcome / onboarding). No colored buttons; the only blue is focus and the switch "on" state.
