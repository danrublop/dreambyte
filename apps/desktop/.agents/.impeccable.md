## Design Context

### Users

Creators, product teams, and developers who build explainer, marketing, and interactive video in a
desktop editor. They work in long sessions that mix prompting the agent, editing on the timeline,
and exporting — usually on a large desktop display.

### Brand Personality

**Precise · calm · instrument-like** — Dreambyte should feel like a professional editing tool, not a
SaaS dashboard or a consumer app. The user's video is the only loud thing on screen.

### Aesthetic Direction

Monochrome editorial chrome with dark as the default theme and a light theme. Neutral surfaces, one
typeface (Inter Variable), black/white actions that invert per theme, and a single functional accent
(Signal Blue) reserved for machine state: playhead, selection, active tab, focus. Dense flat
inspector rows instead of cards. The full token set and component rules live in `docs/EDITOR-DESIGN.md`;
`docs/DESIGN.md` covers generated video scenes and does not apply to the editor UI.

### Design Principles

1. **Content first** — The canvas and timeline carry the color; chrome stays neutral.
2. **One accent, functional only** — Signal Blue means live, selected, or focused. Never decoration.
3. **Density with order** — Group controls under headers with hairlines and spacing, not boxes.
4. **Tokens, not hex** — Every color comes from the CSS variables in `src/app/globals.css`.
5. **No AI-slop patterns** — No gradients, glassmorphism, colored card borders, or emoji as design.
