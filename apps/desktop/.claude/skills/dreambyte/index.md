# Dreambyte Knowledge Bundle

OKF v0.1 conformant. Generated by `scripts/okf/gen-okf-viz.ts` — do not hand-edit the index files.

## Craft packs

- [Audio Craft Rules](/rules/audio.md) [core, audio] - How to wire audio tools — spine, mix dB targets, provider ladder. Read while planning, before any audio call.
- [Scene Output Contract & AI Generation Rules](/rules/generation.md) [lane:avatar] - How to emit a valid scene (React output schema, globals, bridge components, hard DON'Ts) and how to generate avatars, AI images, and AI video clips.
- [Research & Media Sourcing Rules](/rules/research.md) [lane:media] - Which tool sources each asset a scene needs — facts, footage, images, overlays, 3D textures — driven by brief.mediaStrategy.
- [Three.js Scene Rules (r183 + Studio3D SDK)](/rules/three.md) [renderer] - One pack for 3D — studio/lighting, camera, materials/shaders, particles/terrain, post-FX, 3D text, and avatars, plus the ThreeJSLayer bridge contract and export determinism.

- Skill library lives at `src/lib/skills/library/` (renderer skills; its own index.md).

## Routing tags

A craft `rule` carries `tags` that decide when it is injected (intent-router selects
by tag intersection). This vocabulary is the bundle's routing contract — documented
here so any consumer can route without reading the TS:

- `core` — routed for every video (audio).
- `lane:media` / `lane:avatar` — routed when the brief sources media / is avatar-centric.
- `renderer` — routable on demand via `get_routed_craft({ pack })`, not intent-routed.
